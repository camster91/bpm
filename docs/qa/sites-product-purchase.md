# Product purchase checkpoint — 7 October 2026

Added `product.json`, `bpm-sites-product`, native media rendering and progressive enhancement for the purchase/gallery portion of the Sites PDP. This does **not** complete the full source PDP: benefits, application/video, scent story, formula/INCI, value, lifestyle, comparison, review presentation, creator content, FAQ, source jumps and closing remain to be integrated as editable source sections.

Purchase uses Shopify's selected/first available variant, hidden native variant ID, native product form, quantity rules, availability and actual compatible selling-plan allocations. Optional plans expose one-time purchase; required plans select a compatible allocation and disable purchase if none exists. Native names/descriptions, price, checkout charge and per-delivery price replace hardcoded preview subscription copy. Selected plans update the visible price without browser-local cart state. Native server product form/error markup and Admin product description are retained; actual cart submission and backend error behavior remain unverified.

Multi-variant products have a GET selector that reloads the native product URL with the chosen variant. A visible submit button supports no-JS use; JS auto-submits changes so price/availability/plan compatibility are recalculated by Shopify. Existing selling-plan selection resets when a different variant URL is loaded; the displayed compatible controls then require a fresh choice, except required-plan defaults. No client-side inventory assumptions or invented plan schedule. Current store plan names/frequency/terms still require owner reconciliation from the app audit. No subscriptions were changed or purchased.

Gallery uses native image/video/model media and an optional source framed-image picker. With JS, thumbnail links show one media panel and mark the current link; inactive HTML5 video pauses. Without JS all panels remain available and thumbnail anchors can scroll to them. External videos are deliberate external links instead of automatic third-party iframe loads. Hosted video/model markup is routed to native Shopify filters; real playback, 3D runtime, keyboard/media/alt/caption QA and consent behavior remain required. Native app blocks can be added beside purchase controls and in a separate review region; vendor runtime/configuration and duplicate UI remain unverified.

Validation: 70 render checks pass, including variant ID/quantity rules, compatible optional/required plans, unavailable-plan disablement, selected allocation pricing, sold-out purchase prevention, gallery override/count/thumbnails and native media routing. JS syntax checks included. Installed CLI Theme Check: zero errors and existing Adobe RemoteAsset warning. Bundled skill validator was attempted and is still unavailable due to missing `@shopify/theme-check-common`; no checks disabled.

Local fixtures use fabricated variant/plan IDs, terms and prices, original framed package/cream/turntable imagery and a clearly labeled fixture body. Submission and variant selection are disabled. The local Liquid parser replaces native product-form wrappers with a fixture form; it does not emulate Shopify hidden inputs, backend validation, cart/checkout or app APIs. Browser review caught and corrected an incorrect newsletter CSS class on that wrapper before final proof. Actual theme form class is `bpm-product-form`.

Browser in available in-app browser: desktop requested 1440px content/scroll 1425, two purchase columns. Tablet requested 820px content/scroll 805, two columns. At mobile requested 375px a variant-select intrinsic-width overflow was found and fixed with a constrained grid column/select. Final mobile content/scroll widths both 360. Fifteen-pixel difference comes from the scrollbar. Selecting thumbnail 2 shows the cream panel and marks its link current. Selecting the fixture plan updates displayed price to $21.60 CAD; returning to one-time restores $23.99 CAD. These are local presentation/interaction checks, not a subscription transaction. Screenshots: `sites-product-desktop-local.png`, `sites-product-mobile-local.png`. Viewport reset.

Remaining immediate implementation: all PDP editorial/source modules, real product/media/content mappings, source design/motion comparison and merchant controls. Native runtime gates: variant reload/URL/back behavior, large variant catalogs, selling-plan terms/prices/multiple deliveries, quantity/inventory errors, add/update/remove/cart persistence, Shopify Bundles and Judge.me/Subscriptions blocks, checkout handoff, cross-device/accessibility/performance/SEO/claims/analytics. Native model/external/hosted video tests are markup evidence only. No upload, Shopify content/settings write, publication, push or merge occurred.
