# Native product and article structured data checkpoint

The protected Dawn theme export already emits product | structured_data in sections/main-product.liquid (735–737) and article | structured_data in sections/main-article.liquid (291–293). The custom candidate now restores those native serializers once in the main layout through bpm-structured-data. Dispatch requires matching request.page_type and a nonblank current native resource. No schema is emitted by this helper for homepage, collection, directory, blog index, pages, cart, search, 404, customer or private utility routes. Theme editor settings independently disable product or article serialization if a verified integration supplies the complete corresponding schema. Defaults remain enabled, matching the captured Dawn behavior.

Shopify's filter is the data authority: https://shopify.dev/docs/api/liquid/filters/structured_data . Native product output can be Product or ProductGroup depending on variants; article output is Article. Theme code does not construct offers, substitute CAD, invent inventory/reviews, scrape badge HTML or HTML-escape serialized JSON. It passes native objects unchanged. Existing content_for_header and native app blocks remain intact. Review markup is left to the review integration. Actual filter output remains unverified until Shopify renders this theme.

Judge.me's current primary documentation https://judge.me/help/en/articles/8409296-displaying-product-ratings-in-google-search-results says JSON-LD review markup is supplied by the app and depends on installed widget/published reviews. It describes JSON-LD/microdata mismatches and duplicate schema from another provider. No Judge.me setting was changed. The older troubleshooting URL returned 404; the current consolidated article was used instead. Restoring Dawn's native serializer does not prove the app's current settings or graph alignment with ProductGroup. The product theme switch is a targeted escape hatch only after evidence shows another integration provides complete product schema; disabling it blindly could remove offers/availability.
