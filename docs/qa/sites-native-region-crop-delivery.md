# Native region crop and responsive gallery delivery checkpoint

This extends the native-thumbnail checkpoint without rewriting its earlier evidence. The previous inline-SVG thumbnail technique is superseded by native region crops. All recovered raster/SVG files, bytes, hashes and viewports remain unchanged as fallback and provenance.

Shopify image_url supports region crop coordinates and resizing the extracted region: https://shopify.dev/docs/api/liquid/filters/image_url . The gallery helper now resolves the existing Files image only when original width/height match the recorded source geometry. It applies the exact original crop_left, crop_top, crop_width and crop_height to the native image, then uses image_tag for responsive widths, sizes, native dimensions and loading/priority. Full source images cap width at the original crop width. Width candidates are bounded to that cap, so the helper requests no artificial enlargement. Thumbnails use up to 128 crop pixels with 48/64/96/128 candidate sizes and the existing 42/52px display sizes. Full delivery retains native viewport sizes and eager/high priority only when initially selected.

The helper receives native Files context for both main and thumbnail images. Missing Files image or original-dimension mismatch uses the unchanged source SVG. The editor setting Use responsive native source artwork defaults true; false forces recovered SVG delivery for both main and thumbnail. Merchant-uploaded first-gallery overrides keep their existing native path. Ordinary native media, commerce forms and gallery switching are unchanged. A file with matching dimensions can still have changed contents: actual native identity/byte/visual checks remain release gates.

306 LiquidJS rendering checks pass, including all nine full exact-region dispatches and bounded width candidates in addition to thumbnail mapping, fallback and priority checks. Mock image_url replaces existing query arguments rather than appending duplicate width; mock image_tag exposes widths passed by Liquid for tests.
