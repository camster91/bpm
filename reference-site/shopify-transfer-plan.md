## 10% email welcome offer — required flow

Preview implemented site-wide: small butter-coloured bottom-left Get 10% off launcher, pink/cream signup panel, email validation, explicit unselected marketing-consent checkbox, close/Escape and keyboard focus return, and demo success state. Product mobile launcher sits above the sticky Add to bag bar. It opens only on request; no automatic timed popup. No email is sent, stored or subscribed by the public design preview; BPM10-DEMO is not a valid discount.

Shopify implementation: first inspect the existing store email provider and signup flows. Reuse an active provider to avoid duplicate lists or double welcome sends. If no established provider, use Shopify Forms and Shopify's welcome-discount marketing automation. Native Forms supports discounts and automation linkage: https://help.shopify.com/en/manual/promoting-marketing/create-marketing/forms-app/settings/all-forms . Welcome automation: https://help.shopify.com/en/manual/promoting-marketing/create-marketing/shopify-messaging/marketing-automations/create . Map this custom branded launcher to the supported provider integration, preserving accessibility and responsive placement; verify whether native form styling can faithfully reproduce this panel before selecting the implementation.

Proposed discount: 10% welcome offer, one use per customer, subscriber eligibility, no stacking. Confirm first-order eligibility, discounted bundle and subscription treatment, minimum spend, expiry and whether to use an individual code or one audience-restricted code with the owner before activation. Do not silently stack with the existing subscribe-and-save discount. Preview makes no expiry or all-products promise. Hide the launcher after signup and suppress offers for known subscribed visitors where supported; dismissals should remain respected. Do not store email addresses in browser storage.

Flow: visitor opens tab → email + explicit consent → provider validates/subscribes (confirm double-opt-in setting) → success confirms delivery or prompts inbox confirmation → welcome email includes the real discount and product-selection link → checkout validates discount eligibility. Existing subscribers get a clear non-duplicating response; repeat submissions do not send extra welcome emails. Coupon failure, network failure and invalid-email messages must preserve the user's input and explain the next action.

Include final approved terms, sender identity, address and unsubscribe link. Optional later founder/story or usage emails remain drafts until cadence and content approval; suppress discount reminders after purchase. No outbound campaign is authorized by the preview.

Before live activation: verify sender/domain and existing provider, owner-approved offer terms, actual consent and subscriber persistence, exactly one welcome delivery, code at checkout including bundles/subscriptions, unsubscribe behavior, keyboard/mobile placement, duplicate/existing subscriber handling and error states.
